# Comparison of the two translation reviews

TLDR: Gemini (pre-screen) flagged 278 strings; Muse AI corrected 25, all inside Gemini's set. Muse's PDF is cut off at the right margin, so 9 of its 25 correction lines are incomplete and could not be applied as written. 60 strings were changed after a fresh Gemini back-translation check; 52 flagged strings are left for a native speaker. No namespace is marked reviewed. Everything here is model-reviewed, not native-reviewed.

## Inputs and extraction

- `languages-to-check-fixed.json` and `.csv`: only two Burmese items carry reviewer fields (`common.scamTypes.other`, `feedback.reportScam.placeholder`). Both are clean Unicode with no stray spaces.
- Muse PDF: its `CORRECTIONS` dictionary is the only source of corrected text. The code block is clipped at the page margin. Lines stop at about 85 characters in every extraction (`pdftotext` with and without `-layout`, `-raw`, PyMuPDF, pdfplumber) and in the rendered page image, so the missing text is not in the file. 16 of 25 entries are complete (short strings); 9 are cut off, including `report.warnMessage`.
- Burmese by tool: `-raw` has the fewest stray spaces and was used. Plain `pdftotext` adds more (`ပိ တ်`). `-layout` adds them and cuts lines. PyMuPDF doubles marks (`ရှိှိပုံံ`). pdfplumber returns visual order (vowel sign e before the consonant), which is not valid Unicode order. Remaining artifacts were removed by hand (`နို င်` to `နိုင်`, `မက်ဆေ့ ချ်` to `မက်ဆေ့ချ်`, `အလု ပ်` to `အလုပ်`, `ဖွ င့်` to `ဖွင့်`).
- Muse's script would set `reviewer_verdict: ok` on about 2,000 untouched strings and, through `i18n-apply-review.mjs`, mark all 15 namespaces `reviewed: true`. That claims a human review that did not happen. It was not run.
- The review file is one commit older than the app: `common.languageNote.reportsInEnglish` no longer exists, so the after-fixes files drop that row.

## Method for applied fixes

Each candidate passed: placeholders equal to English, NFC and no zero-width characters, Burmese order and A10 YoeShin glyph coverage, length against the current string for short labels, then a blind back-translation (`gemini-3.7-flash`) and a judge call (`gemini-3.8-flash`) for meaning, no added certainty and no dropped content. Muse text was tried first where complete. Where the judge disliked only the wording (stiff), the fix is kept and flagged. The same family of models wrote and judged the text, so this is a cross-check, not a native review.

## Where a model cannot settle it (native speaker needed)

1. Burmese register: written ပါသည် versus spoken ပါတယ် across guide, errors and captions (about 30 items). One policy first, then edits.
2. Burmese "message" spelling မက်ဆေ့ဂျ် versus မက်ဆေ့ချ်, and the shield term (အကာအကွယ် versus ဒိုင်း).
3. Burmese "report" verb (အသိပေး, တိုင်ကြား, သတင်းပို့) and the loanwords malware, trading, store.
4. Thai Scam radar name and `checking.verdict.danger` ("สูง" added).
5. Tagalog plural wording for a count of one (`radar.intro_one`, `radar.reports_one`, `report.seen_one`) and "scam" versus "panloloko".
